## 简介

BMV是一款让可以让你通过导入bmx文件和回放文件来实现对自己游玩的全面复盘和分析，现在支持：

- 回放显示
- 判定计算
- 视频导出（buggy）

（这是我的第一个开源项目，有很多不到位的地方还请多指教。）
